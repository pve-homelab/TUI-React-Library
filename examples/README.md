# Examples

Runnable Vite apps that import the library from source (`../../src/index.ts`).

| App | Path | Default URL | Command |
|-----|------|-------------|---------|
| Kanban demo (herdr-board style) | [`examples/kanban-demo`](./kanban-demo) | http://localhost:5174 | `npm run examples:kanban` |
| tmux dashboard (split panes + status) | [`examples/tmux-dashboard`](./tmux-dashboard) | http://localhost:5175 | `npm run examples:tmux` |

From a workspace folder:

```bash
npm install
npm run examples:kanban
npm run examples:tmux
```
