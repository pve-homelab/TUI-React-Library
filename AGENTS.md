## Learned User Preferences

- Prefer verifying TUI/Kanban UX via runnable apps under `examples/`, not docs alone.
- Treat seamless Kanban card drag-and-drop across columns as a core library requirement (smooth moves, not same-row catch then teleport-on-drop).

## Learned Workspace Facts

- This repo (`tui-react-library`) is a TypeScript React component library for terminal/TUI aesthetics, Kanban boards, and tmux-like split panes/sessions.
- Design inspiration targets are herdr.dev TUI, `nelsonPires5/herdr-board`, and tmux layout/interaction patterns.
- Local demos live at `examples/kanban-demo` and `examples/tmux-dashboard`.
